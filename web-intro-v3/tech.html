We deliberately didn't use a ready-made vibration package. Those usually offer "vibrate for X milliseconds". We need exact rhythms with different strengths played as one uninterrupted pattern, so we wrote a small bridge straight to Android's own API.

How the code is organised

The app follows Clean Architecture: separate layers with one job each. The core rules (what Braille is, how timing works, how answers are scored) don't depend on screens, storage or hardware, so they are easy to test and easy to swap.

ScreensWelcome, Home, Read, Talk to me, Train, Progress, Settings, and the animated Braille cell.
ControllersRiverpod providers that run playback and training sessions and hold your settings.
Domain (the brain)Pure Dart: Braille translator, timing engine, curriculum, analytics, data models.
DataHive storage, speech recognition, the vibration bridge, the AI agent placeholder.
AndroidKotlin HapticChannel plays the waveform on the motor.

The heart of it, in code

This Dart function turns one Braille cell into a rhythm. It is the whole idea of temporal Braille in about twenty lines (lib/domain/engine/haptic_translation_engine.dart):

if (p.cellAnchorEnabled) {                 // soft start-of-letter tick
  out.pulse(anchor(p.anchorDuration, p.anchorIntensity));
  out.silence(intra);
}
for (var slot = 0; slot < 6; slot++) {           // the six dots, in order
  if (slot > 0) out.silence(intra);              // gap between dots
  if (cell.isRaisedAt(slot)) {
    out.pulse(dot(p.dotDuration, p.intensity, slot)); // raised: tap
  } else {
    out.silence(p.emptySlotDuration);                // flat: silence
  }
}

And this Kotlin code plays the result on the phone (android/…/HapticChannel.kt). On Android 13 and newer it is marked as accessibility vibration, so it still works when the user has turned off touch vibration:

val effect = VibrationEffect.createWaveform(timings, amplitudes, -1)  // -1: play once
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
    v.vibrate(effect, VibrationAttributes.createForUsage(USAGE_ACCESSIBILITY))
} else {
    v.vibrate(effect)
}

Ready for AI

  • All text passes through one interface, ITextProcessor, so an AI could summarise a long email before it is vibrated.
  • Learning data exports as versioned JSON that an AI can read to spot where someone struggles.
  • HapticProfileModel.scaled() slows or speeds up every pause at once, so an AI coach could adjust the reading speed automatically.
  • An empty AgentService marks where the AI connection will go.

This website

Plain HTML, CSS and JavaScript with no framework and no build step. The background dot field is drawn on a canvas. The "Feel it" demo uses the same timing rules as the app and the browser's Vibration API, which works in Chrome on Android. Fonts: Bricolage Grotesque for headings and Atkinson Hyperlegible for text.
