Feel every word.

HaptiBraille turns text into Braille you feel through your phone's vibration, so people who are blind or deafblind can read messages privately. No sound, no screen, no extra hardware.

The story, in eight chapters

Read them in order, or jump to the part you care about. Each chapter number is written in Braille: the number sign, then a letter.

  1. The problem

    Screen readers aren't private and don't work for deafblind people. Braille displays cost thousands.

  2. The solution

    Six Braille dots played one after another: a tap for a raised dot, a silence for a flat one.

  3. Who it's for

    Deafblind, blind and low-vision people, plus families, carers and teachers.

  4. Why we're doing this

    Privacy, cost, independence, and a skill that only 1 in 10 people have had the chance to learn.

  5. What inspired us

    Night writing, Louis Braille, Morse code, the tap code, and modern phone vibration.

  6. How it works

    The five-step pipeline, the timing inside one letter, training rules and progress maths.

  7. What we're building

    Read, Talk to me, Train, Progress and Settings, and what isn't finished yet.

  8. The tech stack

    Languages, tools, packages, architecture and the key code.

Install it in three steps

HaptiBraille isn't on the Play Store yet, so you install the app file directly. It takes about a minute.

  1. Download

    On your Android phone, tap Download for Android. The file is called HaptiBraille.apk.

  2. Allow the install

    Open the file. If Android asks, allow installs from your browser. If Play Protect warns about an unknown app, choose More details, then Install anyway.

  3. Start learning

    Open HaptiBraille and tap Start learning. The first level teaches you to feel single dots in a few minutes.

Using an iPhone?

The iPhone version isn't ready yet. The app is built with Flutter, so the same code will run on iOS once the iPhone vibration code is finished. Until then, you can try the rhythm above in any browser and watch the dots.
